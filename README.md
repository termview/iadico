# IADICO
## Internet Archive-based DIachronic COrpus for Document- and Timeline-oriented Studies

We introduce **IADICO** (Internet Archive-based DIachronic COrpus), a novel corpus for timeline-based and document-aware NLP studies. Some NLP applications, such as automatic term processing, target elements that belong to documents rather than to textual corpora regarded as linguistic samples. Nevertheless, datasets that provide documents in a wide range of topics and domains with systematic document information are scarce. This motivated us to develop IADICO. A key characteristic of IADICO compared to existing datasets is that it provides collections of English textual documents with time stamps and other document information in 29 domains. 
IADICO uses Internet Archive, which offers a large amount of multimedia documents with metadata including time stamps. It also allows a dynamic keyword search and is convenient to create tailored datasets for specific research. 
In this paper, we first describe the creation of IADICO. As a use case, we analyze technical terms in IADICO from a chronological point of view based on document types, such as books, journals, newspapers or magazines.
